模块内的顺序，能否变成共享原子的等级？

用有限的结构化声明探索：同一 .gss 模块内，各目标的冲突顺序能否编码为「语义 + 等级」版本，复用后仍保留当前节点的原生 CSS 结果？这不是 GSS 解析器，不接入编译器。

只探索 background-color、真实 hover / focus / aria-pressed="true"、两档类级特异性，以及普通 / !important。每个目标只属于一个模块。同一节点组合多个模块作用域不在范围内，当前排序对此不安全：共享等级不能表达模块间作者顺序。

当前状态

算法：按稳定模块 / 目标 / 源顺序重算；每个「模块、目标、属性、importance、特异性」组按源顺序编号 1…n（保守，不分析互斥，不求最优）。语义包含属性、值、谓词、特异性、importance；身份再加等级，不含模块名。只生成用到的版本。最终在相同属性 / importance / 特异性域内按等级递增发射，其他域交给浏览器级联。不是跨 importance 的胜者算法。

模块 / 目标（稳定顺序）源序条件 → 值特异性 / importance等级类 / 复用次数

原生 .scope 与原子类各贡献一档特异性，谓词再加一档；强声明再加 .boost。目标定位放在 :where 内，不增加权重。不存在替代伪状态属性。
