# 将 semantic reference CSS 作为正式测试能力

GSS-l 第一版提供独立 testing API `compileGssReference()`，生成保持 authored selector/cascade/declaration grouping 的 reference CSS与对应 style mapping，用于和 atomic输出在隔离浏览器环境中做 computed-style oracle比较。Reference能力不进入 production默认输出或 bundle。

## Accepted testing seam and bounded implementation slices

`@gss-l/testing` now owns the synchronous, framework-independent API:

```ts
function compileGssReference(
  input: { config: GssCompilerConfig; modules: readonly ReplaceStylesheetInput[] },
  ports?: { resolveAssetUrl?: (identity: string) => string },
): ReferenceCompileResult;
```

The input and port types are exported as `CompileGssReferenceInput` and `ReferenceCompilerPorts`. The result is discriminated by `success`: success returns `css`, `scopeSchemas` (keyed by input Module id, using public `ScopeSchema`), and `diagnostics`; failure returns only `diagnostics`, never partial CSS/mappings. There is no retained session state. Duplicate logical Module ids fail. Output is globally partitioned base-first then by registered condition rank, with project-relative Module identity stabilizing output within each rank. Authored order inside corresponding groups and declaration grouping/order remain unchanged; Module identity is not a semantic winner for arbitrary composed exports.

The reference accepts plain ASCII local classes (`[A-Za-z_][A-Za-z0-9_-]*`) and whitespace descendant paths, with `content`, `color`, `background-color`, `display`, `width`, `height`, and physical `margin`/`padding` shorthand and four longhands. Declaration order, grouping, comments, and `!important` remain authored. Basic values remain opaque CSS token streams, but functions and escapes are rejected; ordinary quoted content may contain literal parentheses. The bounded background-image extension below is the only URL/escape exception. Exact-property duplicates at equal importance fail, as in the GSS declaration contract. Separate normal/important declarations are retained.

Reference names reversibly encode logical Module id and authored class, independently of atomic names. The same authored class has one reference token per Module, including when it appears at different scope paths. Only declared paths and their structural prefixes are mapped. Actual matching ancestor DOM lets the browser perform ordered-subsequence accumulation, specificity, importance, and shorthand/longhand cascade; the reference never computes winners.

The next bounded slice retains current or ancestor `:checked`/`:disabled` (including a same-node intersection, states on one path node only), or one current/ancestor data-/ARIA equality attribute without pseudos. Attribute names match `(data|aria)-[a-z][a-z0-9_-]*`; only `=` and optional CSS whitespace are accepted. Values are unescaped single-/double-quoted text (excluding the matching quote, NUL/LF/CR/FF), or unquoted `[A-Za-z_][A-Za-z0-9_-]*`; empty quoted strings are valid. No namespace, flags, other operators, escapes or comments outside attribute strings are accepted. Class AST nodes alone are renamed, leaving comment/attribute-string class text intact. This is not a full GSS validator and does not resolve state ambiguity or redefine production capability limits.

The next bounded pseudo slice accepts terminal `::before` and `::after` on existing ownership/descendant paths, optionally with current checked/disabled states and their intersection. The base ScopeSchema path is unchanged. `content` follows the same opaque no-function/no-escape policy; quoted strings and class-looking text are preserved, with no injected content or applicability emulation (ADR-0021). Ancestor-state/attribute + pseudo-element combinations remain outside this reference slice.

Unsupported syntax/configuration fails explicitly: selector lists/nesting, other/functional pseudos, attributes outside that grammar, multi-node states, multiple attributes or attribute/pseudo combinations, other/misplaced/repeated pseudo-elements, ancestor-state + pseudo-element combinations, child/sibling/runtime relations, at-rules/configurations outside the bounded registered-condition/layer slice below, resources/properties outside the bounded lists, including the background-image extension below. Empty condition/layer registrations and either atomic fallback policy are accepted; no fallback/planning is performed. `resolveAssetUrl` is invoked only for bound background-image identities under the extension below. This restriction prevents a configured GSS precedence from being silently replaced with native authored order. These are **current reference coverage limits**, not changes to product capabilities or new product deferrals.

The package has no production dependents. Public compiler shapes are type-only imports; runtime parsing uses PostCSS and the independent `postcss-selector-parser` syntax library, with local lexical Module-path infrastructure. It imports no production compiler implementation, winner/pruning service, atom identity, planner, or allocator, and performs no filesystem/browser/framework work.

The bounded browser harness (`packages/testing/browser`, command and assertions in `packages/testing/README.md`) compiles the atomic side through the public production API only. It renders identical DOM with substituted mappings into isolated documents, checks literal expected values independently on each side, and retains a deliberately corrupted atomic-CSS negative control. Parent native `agent_browser` acceptance passed **twenty-five fixtures / 575 computed-value comparisons** (fourteen compiled-reference fixtures plus eleven hand-authored contextual goldens), with empty differences and expected failures: ownership/Module isolation, ADR-0011 accumulation, physical shorthand/longhand effects and importance, native checkbox states, ancestor fieldset and data-/ARIA conditions, forward/reversed ancestor cascade with simultaneous current conditions, and repeated-source positive/negative embeddings. Phases enter, exit and restore native DOM properties/attributes, and differences include phase and actual state. The original ancestor attribute counterexample remains unchanged: `margin-left` is `1px → 9px → 1px → 1px` on both sides. The checkbox's approved margin probe is `1px` on both sides in all five phases; native checkbox padding is not used as an oracle. The corruption control still detects reference `9px` versus atomic `123px`.

Eleven additional contextual-boundary browser fixtures use hand-authored native CSS and explicit mappings for child relations and `:has()`; these are test goldens, not new `compileGssReference` capabilities. They guard unrelated-condition toggles, same-source child tie precedence, greater authored specificity/importance, and observed match/no-match/restoration.

The compiler repair uses proven target/source-prefix bindings rather than blanket marker sharing, preserves authored specificity for base/current/ancestor instances, and resolves effect winners only inside a closed bound-predicate candidate set. Incomparable coactive ties fail rather than falling back to generated-name order. Namespace-bearing class AST nodes fail before rewriting, with public no-partial-output regressions. This is bounded manual browser evidence, not the complete state/condition/resource oracle, browser CI or Pilot. Ancestor checked remains API-only coverage.

Two pseudo fixtures add literal host/before/after content, color, display and size readings, Module isolation, importance, absent content, descendant/subsequence/structural-prefix accumulation and native button disabled entry/exit. Diagnostics identify the sampled subject. A pseudo-only atomic color corruption must be detected while host/after controls remain unchanged; both corruption controls passed. Checked + pseudo remains API-only coverage. The public-session red structural-prefix regression led to a bounded repair: pseudo groups now consider same-layer/condition declared paths/prefixes, requiring descendant ownership proof for multi-class candidates; standalone terminal classes can match runtime-derived targets without inferring sibling ancestry. Declared pseudo paths and structural prefixes are materialized independently of retained declarations, including empty rules, so the public ScopeSchema remains available. Winning declaration provenance is retained through expansion and emitted with authored specificity on target/priority-qualified atoms, never by strengthening a weaker shared atom. Accumulated candidates are validated per pseudo subject before commit or preserved fallback; unresolved coactive ties reject transactionally, while a dominating explicit intersection is accepted. Authored order remains restricted to closed bound-predicate winner sets, never global authored-order/name winners. No public API or product semantics changed.

Review of the initial 21-fixture / 395-comparison slice found two blocking counterexamples despite its passing oracle corpus: lost specificity across expanded state groups and unchecked cross-path coactivity. Public-session red/green tests now cover both, LKG retention before fallback, priority isolation and dominating/non-dominating intersections. Four further native fixtures check forward/reverse specificity and importance on real disabled buttons under matching ancestry, including unrelated/standalone same-value atoms and element/before/after isolation/restoration. The expanded parent native gate passed 25 fixtures / 575 comparisons, with both corruption controls effective. This applies existing ADR-0011/0013/0021/0027 semantics; it adds no public API or product precedence.

## Registered-condition and named-layer reference slice

The unchanged public seam now accepts at most one nonempty `config.conditions` kind per invocation. Registered **flat** media/container queries use exactly `(min-width: Npx)` / `(max-width: Npx)` (`N` is zero or a positive integer without leading zeros); container optionally prefixes one simple ASCII name and a space. Supports is exactly `(display: block)`, `(display: grid)` or `(display: gss-unsupported)`. Configured query lists must be unique; unused registrations and empty arrays are allowed. Names use `[A-Za-z_][A-Za-z0-9_-]*`, excluding CSS-wide keywords and `default`/`none` case-insensitively. Container names additionally exclude the query operators `not`, `and`, and `or` case-insensitively; these remain valid layer names. Query spacing is exact as shown; there is no general query normalization.

Unique simple names in `config.layers` emit one global native order prelude. Registered condition blocks may appear at root or inside one outer configured layer block; ordinary unlayered rules stay unlayered. Complete authored groups are partitioned by base-first/configured condition rank globally, retaining wrapper structure (splitting enclosing layer blocks when needed), source selector specificity, declaration grouping/order/importance, comments, quoted content and namespaced empty-path mappings. The reference never resolves atomic winners or manually reverses important declarations: native cascade layers decide normal/important/unlayered precedence. This independently expresses ADR-0003/0023/0026/0027 rather than treating arbitrary authored order as the oracle.

Mixed nonempty kinds, compound/nested conditions, layer-inside-condition, nested/dotted/anonymous/unregistered layers, authored layer statements, unregistered queries, unknown condition keys and other query grammars fail transactionally. Cross-kind/compound/nested reference ordering remains incomplete; this slice makes no new product semantics decision. Other resource bindings remain unsupported; background-image bindings are covered by the next extension below. Production warnings, fallback, domain model and public API are unchanged; no Compiler edits were needed.

Parent native `agent_browser` acceptance passed **43 fixtures / 803 comparisons**, retaining the existing **25 / 575** and adding **18 / 228**, all with zero differences/literal failures. Twelve registered-condition fixtures cross kind/source/config order and reverse Module registration; base rank, descendant specificity and importance retain literal winners. Media iframe and named container provider sizes enter no-match/first-only/restored-both states (640 → 100 → 300 → 640). Supports probes record actual block/grid true and gss-unsupported false on baseline/recheck, not fictional runtime supports toggles. Four native layer fixtures test source/config reversal and normal/important/unlayered priority; two outer-layer/media fixtures test condition rank within important layers and restoration. Setup-only container styles are identical and separate from oracle declarations.

All four corruption controls passed. The condition-only override detects `padding-left: 7px` versus `123px` at baseline/restored-both, with nonmatching phases unchanged. Reversing the atomic layer prelude flips normal blue→red and important/unlayered-important red→blue, leaving unlayered normal unchanged. Original element and pseudo controls remain effective; pseudo host/after controls are unchanged. Readings include viewport, matchMedia/CSS.supports and container width alongside phase/native state. Public reference tests passed (134); workspace verification passed (439 tests plus lint/build/typecheck). This is bounded manual native coverage, not the full oracle/React corpus, browser CI or Pilot. See the [testing README](../../packages/testing/README.md) for exact grammar and replay assertions.

Review found that the initial 43/803 passing corpus did not exercise container-query operators used as names: `not (min-width: 200px)` escaped the bounded gate as a native negated query. The reference now rejects `not`/`and`/`or` case-insensitively in the container-name branch only. Public red/green tests cover used and unused registrations with diagnostics-only failure and retain valid layer names. This repairs fail-closed coverage without Compiler/API or product-semantic changes. Parent freshly opened the rebuilt server after the fix: native acceptance again passed **43 fixtures / 803 comparisons**, zero differences/literal failures, all four corruption controls detected and pseudo controls unchanged. No fixture expectations or Compiler code changed.

## Asset binding and background-image reference slice

The existing input/output/`resolveAssetUrl` port is unchanged. Reference `background-image` accepts exactly case-insensitive `none` or one case-insensitive literal `url(...)`, with optional outer declaration CSS whitespace and CSS whitespace around a nonempty single-/double-quoted or unquoted argument. Quoted text excludes an unescaped matching quote; unquoted text excludes unescaped whitespace, quotes, parentheses and comments. CSS simple escapes and 1–6 hex-digit escapes (one optional CSS whitespace terminator, including CRLF) are supported **only inside the URL argument**. Raw/decoded U+0000–001F and U+007F, unpaired surrogates, invalid scalar escapes and escaped newline continuations fail. Terminator whitespace is not URL content. Lists, gradients, other functions/modifiers, escaped function names and comments outside quoted URL text fail. Font/keyframe/custom-property support and mixed/nested conditions are not added. Existing content strings such as `"url(fake.svg)"` and comments remain untouched, with no Asset discovery inside them and no general function/escape expansion.

Per ADR-0050, the binding key is **CSS-decoded, never URI-decoded**; identity is exact opaque text, preserving Unicode, case, query and fragment distinctions. Bindings are Module-local, nonempty, must match a discovered URL, and may repeat only with the identical identity. All configuration, Modules, sources and bindings validate before any resolver callback. Bound identities resolve once each per invocation (including aliases across Modules); delivery strings are safely quoted CSS strings, not text placeholders. Unbound URLs preserve authored spelling without automatic file resolution, and delivery changes cannot influence reference names/mappings. The compiler has no IO, browser/framework code or production runtime imports.

The reference's existing diagnostics-only failure contract applies to missing resolver, empty/non-string output and resolver exceptions (`reference-asset-resolution-failed`); no partial CSS/schema escapes. This does not change production finalize's exception behavior. Earlier host callback side effects cannot be rolled back after a later callback fails, but there is no retained resolver cache or partial result.

Public API red/green coverage: **226 reference tests (92 new)**, including grammar boundaries, exact decoding, opaque identities, repeated identity caching, unchanged mappings across delivery changes, safe injection-resistant encoding, same-URL Module isolation, unknown/empty/conflicting/identical bindings, no-binding/no-resolver behavior, exceptions and validation-before-callback. Workspace verification: **531 tests**, lint/build/typecheck. No production code or public API changed.

Parent native gate passed **46 fixtures / 819 comparisons** with no differences/literal failures, retaining **43 / 803** and all four previous corruption controls. Three new fixtures independently compile literal background-image expectations for Module isolation under two deliveries and layer/media/current-disabled/before composition. Exact owned SVG routes provide deterministic bytes; each side's actual computed URL is fetched/decoded and compared to literal natural dimensions. The fifth corruption control detects a successfully loaded **wrong** Asset (3x2 versus 11x7), with only the intended Module's URL/dimensions changed; pseudo/asset controls remain otherwise unchanged. Evidence concerns selected URLs and decoded dimensions, **not painted background pixels**. Full oracle/resource/React coverage, browser CI and Pilot remain incomplete. See the testing README for exact replay and exclusions; none are new product deferrals.

Review follow-up: the initial 46/819 native pass did not cover PostCSS declaration-value trivia. Leading value comments in `raws.between` now reject before any callback, while standalone comments and quoted URL comment text remain preserved. Outer declaration whitespace (space/tab/LF/CR/FF only) is removed for grammar validation, not from URL contents or unbound output; `url(a) ;` and `none ;` are valid. Twenty public red/green regressions pin these existing grammar boundaries, including no partial output/zero callbacks and non-CSS-whitespace negatives. No production semantics, fixtures or expectations changed. Parent post-fix native revalidation freshly reopened the rebuilt server and passed **46 fixtures / 819 comparisons**, zero differences/literal failures, all five controls detected and pseudo/asset controls unchanged.

## Module-local keyframes and static animation reference slice

The public `compileGssReference` API/result/ports are unchanged. Definitions are **root-only** `@keyframes name { ... }`. Names are case-sensitive unquoted `[A-Za-z_][A-Za-z0-9_-]*`, excluding CSS-wide keywords, `default` and `none` case-insensitively. Unique definitions (including empty definitions and resource-only Modules) are retained independently of use. Duplicate names, even identical definitions, fail. Names use an independent reversible `gss_ref_keyframes_<logical-Module>__<authored-symbol>` namespace, separate from reference classes. Definitions are collected before references, so forward references work; undefined names retain external CSS semantics. Frame selectors never enter ScopeSchema; empty ordinary paths/prefixes remain mapped.

Exact frame grammar: lowercase `from` / `to` or one percentage from 0 through 100. Numbers match `(0|[1-9][0-9]*)(\.[0-9]+)?` (no leading zeros, exponent or leading-dot decimal). Duplicate numeric offsets, including `from`/`0%` and `to`/`100%`, fail. Empty frames are valid. Frame declarations are only nonnegative number `px` width/height, or color/background-color with `red`, `blue`, `green`, `black`, `white` (units/colors case-insensitive). Frame declaration order/grouping stays authored. Duplicate properties, frame `!important`, selector lists, other frame properties, functions/URLs, nesting and comment/escape tokens inside selector/name/value syntax fail; standalone comment nodes remain untouched.

Ordinary ownership rules add these **single-value** longhands (CSS outer whitespace allowed; units/keywords case-insensitive):

- `animation-name`: one symbol as above, or `none`.
- `animation-duration`: nonnegative number `s` / `ms`; `animation-delay`: the same with optional `+` / `-` sign.
- `animation-iteration-count`: nonnegative number or `infinite`.
- `animation-play-state`: `paused` / `running`.
- `animation-timing-function`: `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `step-start`, `step-end`.
- `animation-direction`: `normal`, `reverse`, `alternate`, `alternate-reverse`.
- `animation-fill-mode`: `none`, `forwards`, `backwards`, `both`.

Ordinary importance/duplicate-property policy is unchanged. Lists, shorthand, quoted names, CSS-wide values, escapes, `var(...)` and other functions or value comments fail explicitly, including comments hidden in PostCSS raws. Quoted ordinary content and standalone comments are not rewritten. Root definitions may be referenced from the already supported registered condition/layer wrappers (**API coverage only**); condition/layer-scoped definitions, vendor definitions and resource combinations inside frames (including Assets) remain excluded. ADR-0024 production support for lists, shorthand, opaque `var(...)` and condition-scoped definitions is unchanged: these are reference coverage boundaries, not product deferrals. Existing background-image bindings and all-input validation before any resolver callback remain intact. No Compiler implementation is imported at runtime or copied.

Browser fixtures add paused, deterministic static metadata only: cross-Module equal symbols with different frames, forward references, reversed Module registration, and percentage offsets. Each side renders identical isolated DOM. A fixture-authored nonanimated probe scope supplies that side's generated name only as transport alignment; it is never a frame/timing expectation. Distinct Module probes must have distinct non-`none` names. Each target requires exactly one actual CSSAnimation, matching computed/probe/animation names and actual KeyframeEffect.target; successful association is normalized to the literal Module/authored-symbol label. Native `Animation.ready` and frame readiness precede readings, with no wall-clock progress sampling. Computed duration/delay/iterations/play-state, actual effect timing, frame count/offsets and exact frame properties independently match literal fixture data. Missing animation/association fails rather than being skipped.

The sixth control locates exactly the A probe's root CSSOM keyframe definition and verifies its removal. It must detect count `1 → 0` and four other missing/mismatched A metadata readings, while A computed declaration metadata, B's animation/frames and unrelated color remain unchanged. Arbitrary exceptions cannot count as detected corruption. This checks resource delivery/association, **not painted pixels**. Existing 46 fixtures / 819 literal comparisons and all five controls remain unchanged. Full oracle/resource/React corpus, browser CI and Pilot remain incomplete.

Public red/green evidence: initial forward-reference failure, plus three PostCSS name/frame-trivia failures before their fixes; **91 new tests / 317 reference tests / 622 workspace tests**, lint/build/typecheck and `git diff --check` pass. The earlier unsupported resource-only width test is now a positive keyframe regression; its unsupported transform counterpart remains negative. No production code or testing public API changed. Parent freshly reopened the owned strict-port page with native `agent_browser`: **passed, 49 fixtures / 875 comparisons**, zero differences/literal failures, all six controls detected; pseudo/asset/keyframes controls unchanged and keyframes definition removal verified. Original 46 / 819 expectations and five controls are retained. Build/typecheck alone is not browser evidence.

Native red/repair evidence: the first expanded run (49 / 870) had four literal `motion-b` timing failures across both sides of the forward/reversed fixtures, with zero atomic/reference differences and all six controls effective. Parent inspected the actual browser: computed animation-timing-function was `ease-in`, effect-level `getTiming().easing` was `linear`, and both keyframe easings were `ease-in`. The harness had conflated CSS per-keyframe easing with effect-level easing. It now retains an independent effect-level `linear` literal and explicitly asserts every frame easing plus computed animation-timing-function (five additional readings, total 875). This is a harness correction, not evidence of a Compiler defect; no expected easing check was removed.

The reference-only fix validates the complete separator as CSS whitespace, one colon, CSS whitespace, and rejects comment-bearing importance trivia before callbacks. Nine new public regressions assert diagnostics-only/zero-callback failures and preserve all five CSS whitespace characters with mixed-case ordinary `!important`; frame importance remains prohibited. Verification passed **326 reference tests (100 keyframe) / 631 workspace tests**, lint/build/typecheck and diff check. No production/API/harness/fixture/expectation changes. ## Consequences (full target, beyond the first slice)

- Reference renderer可以共享 parser、selector AST、source range和asset resolver，但不经过 winner pruning、atomic identity、property排序或 contextual atom planner，降低共同错误导致假通过的风险。
- Reference 与 atomic fixture使用相同 DOM/状态脚本和不同 class mapping；比较 touched properties、property-effect longhands、custom properties、pseudo-elements、state、condition、relation和 layer/important结果。
- 快速 CI覆盖 IR/CSS/manifest/reference snapshot；浏览器 CI覆盖代表性 oracle corpus，差异报告 selector path、state、condition、property、两侧值与 source range。
- Keyframe/animation优先比较静态 metadata和可稳定采样结果；font resource使用结构/manifest验证，避免平台字体渲染噪声。
- Testing API置于独立 testing seam/package，production compiler和React Adapter不依赖它。
- Pilot验收要求零未解释 computed-style difference。
